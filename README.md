# Sales Analytics Dashboard

An interactive sales analytics dashboard built with **Power BI**, **Python**, and **Excel**. The project cleans and analyzes sales data to make revenue, product performance, and customer trends easier to explore.

## Project goals

- Prepare sales data for analysis.
- Examine revenue and product performance.
- Explore customer trends.
- Present findings through interactive charts and reports.

## Tools

- **Power BI** — interactive dashboard and visualizations
- **Python** — data cleaning and analysis
- **Excel** — data review and preparation

## Workflow

1. Review and clean the sales data.
2. Analyze revenue, product performance, and customer trends.
3. Build interactive charts and reports in Power BI.

## Results

The dashboard provides an interactive view of key sales areas, helping users explore the data and identify patterns in revenue, products, and customers.
